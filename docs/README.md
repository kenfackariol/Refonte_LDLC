# Document de conception

| Fichier | Rôle |
|---|---|
| [`Document_de_conception.pdf`](Document_de_conception.pdf) | **Livrable** : synthèse de la conception (10 pages maximum) |
| [`conception.html`](conception.html) | Source du PDF |

**Régénérer le PDF :** ouvrir `conception.html` dans Chrome ou Edge (le schéma d'architecture est dessiné à l'ouverture, connexion Internet requise), puis *Imprimer → Enregistrer au format PDF*, format A4, marges « Aucune », option « Graphiques d'arrière-plan » cochée.

Chaque lot est détaillé dans son propre dossier (`lot1-…` à `lot4-…`), avec des scripts exécutables. Le README du dépôt est à la [racine](../README.md).
